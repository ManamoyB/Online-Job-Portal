## 📌 Project Overview
This project was developed as part of an academic **Database Management System (DBMS)** coursework requirement, where the objective was to design and implement a complete web-based application backed by a properly structured relational database.

The chosen problem domain was an **Online Job Portal**, enabling interaction between job seekers and recruiters through a centralized digital platform.

This repository demonstrates not only implementation but also engineering thinking across:

- database schema design
- entity relationship modeling
- backend data connectivity
- user workflow planning
- web application architecture
- structured documentation
- project presentation readiness

---

## 🎯 Problem Statement
Traditional recruitment workflows can be fragmented, slow, and difficult to manage manually.

This project addresses that problem by creating a centralized online platform where:

- job seekers can search and apply for jobs
- recruiters can post and manage openings
- application data is stored efficiently in a structured database
- user interactions are tracked reliably through backend connectivity
